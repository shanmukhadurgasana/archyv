# Academic Document Management System

**Frontend:** [https://archyv-five.vercel.app]  
**Backend:** [https://archyv-cwub.onrender.com]

## 📌 About the Project

This is a **web-based Academic Document Management System** designed for educational institutions.

It provides a centralized platform where **Admins and Faculty** can securely upload, manage, approve, share, and access academic documents.

The system helps reduce scattered file storage and provides better **security, organization, and access control**.

## 🎯 Problem

Academic documents are often stored in different computers, email accounts, messaging apps, or cloud folders. This makes it difficult to manage documents, control access, and track activities.

This system provides one centralized platform to manage these documents securely.

## 👥 Users

### Admin
- Manage faculty
- View uploaded documents
- Approve or reject documents
- Control document access
- Manage departments and academic years
- View activity logs
- Manage deleted documents

### Faculty
- Upload documents
- View uploaded documents
- Check approval status
- Access permitted documents
- Download shared documents

## ✨ Main Features

- 🔐 Role-based login
- 📤 Document upload
- ✅ Admin approval/rejection
- 👥 Faculty-specific document access
- 🔑 Passkey authentication
- 🛡️ Two-factor authentication
- 📋 Audit logs
- 🗑️ Trash and document recovery
- 📊 Dashboard statistics
- 🗂️ Department and academic-year organization
- ☁️ Google Drive file storage

## 🔄 How It Works

Faculty uploads document
          ↓
    Admin reviews
          ↓
   Approve / Reject
          ↓
   Set access permissions
          ↓
Faculty accesses the document
